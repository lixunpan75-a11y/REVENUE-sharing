# 分帳小幫手

原生 HTML、CSS 與 JavaScript 製作的繁體中文分帳網站，不需建置工具、套件安裝、登入或後端服務。

## 開啟方式

1. 下載或 clone 此 repository。
2. 在瀏覽器直接開啟 `index.html`。
3. 若瀏覽器限制 `file://` 頁面的本機儲存，於專案目錄啟動靜態伺服器，再瀏覽 `http://localhost:8000`，例如：
   - Python：`python3 -m http.server 8000`

網站資料儲存在目前瀏覽器的 `localStorage`；不同瀏覽器或裝置不會同步。

## 操作

- 初次開啟為空白工作區，不會預載示範群組、示範費用或預設成員。
- 點選「建立新群組」，輸入活動名稱與至少兩位成員開始使用。
- 可新增、編輯及刪除費用，選擇付款人與分攤對象，使用平均或自訂分攤。
- 在「結算建議」標記還款完成後，未結清金額會自動重新計算。
- 「重設示範資料」目前會改為清空資料並回到空白狀態；這會刪除目前瀏覽器保存的群組與費用。
