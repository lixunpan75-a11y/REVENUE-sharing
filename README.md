# 分帳小幫手

原生 HTML、CSS 與 JavaScript 製作的繁體中文分帳示範網站，不需建置工具、套件安裝、登入或後端服務。

## 開啟方式

1. 下載或 clone 此 repository。
2. 在瀏覽器直接開啟 `index.html`。
3. 若瀏覽器限制 `file://` 頁面的本機儲存，於專案目錄啟動任一靜態檔案伺服器，再瀏覽 `http://localhost:8000`，例如：
   - Python：`python3 -m http.server 8000`
   - Node.js（若已安裝）：`npx serve .`

網站資料儲存在目前瀏覽器的 `localStorage`，重新整理後會保留；不同瀏覽器或裝置不會同步。

## 操作

- 預設提供「墾丁慢旅行」示範群組，可立即查看費用、每人餘額和還款建議。
- 建立群組時，每位成員名稱各佔一行；之後可從「成員管理」新增成員。
- 新增費用可選擇付款人、分攤成員、平均分攤或自訂分攤，並編輯或刪除費用。
- 在「結算建議」標記還款完成後，尚未結清的建議會重新計算。
- 「重設示範資料」會取代目前瀏覽器儲存的資料。
